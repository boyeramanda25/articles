# 考试主题切换只改 CSS 变量不动结构

<!-- content-workspace-job:17544e13-4333-4f3e-a3f5-7ecd5cbf8372 -->

## 问题场景

考试后台要支持深浅两套主题，原先每个组件都写死了颜色，改一次要动几十个文件。

## 实现步骤

在根选择器上定义颜色变量，组件样式一律引用变量而不是字面值。

```css
:root {
  --bg: #ffffff;
  --fg: #1f2328;
  --line: #d8dee4;
}
:root[data-theme="dark"] {
  --bg: #16181d;
  --fg: #e6edf3;
  --line: #30363d;
}
```

切换主题时只改根节点的类名，由类名覆盖变量取值。

```javascript
.card {
  background: var(--bg);
  color: var(--fg);
  border: 1px solid var(--line);
  padding: 12px 16px;
}
```

把选择结果写入本地存储，刷新后先读回再渲染，避免闪白。

```javascript
const root = document.documentElement;
function apply(mode) {
  root.dataset.theme = mode;
  localStorage.setItem('exam-theme', mode);
}
```

## 注意事项

变量要定义在包含所有组件的作用域上，写在组件内部无法被全局覆盖；内联样式优先级更高，会盖掉变量。

对于刚接手的同学，要明确各项资源的释放时机，确保线上行为始终可控。

在多人协作的项目里，应当限定作用范围避免影响其他业务，使整体改动风险可控。

在实际落地时，建议先在小流量环境验证行为是否符合预期，减少不必要的返工成本。

在资源受限的环境下，要避免在高峰期执行这类操作，避免问题积累到难以收场。
