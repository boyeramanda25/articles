# 发票表深分页查询改用延迟关联

<!-- content-workspace-job:d68e9a4b-cf56-4c2f-89be-4889fe423eb8 -->

## 问题场景

发票表的后台列表翻到几千页时接口直接超时，LIMIT OFFSET 越往后越慢，因为前面那些行虽然不返回，却照样要被读取和丢弃。

## 实现步骤

先用覆盖索引把目标页的主键捞出来，这一步不回表，扫描量可控。

```sql
SELECT id FROM invoices WHERE total > 300 ORDER BY id LIMIT 20 OFFSET 200000;
```

再拿这批主键回表取完整字段，回表次数等于页大小，与偏移量无关。

```sql
SELECT a.* FROM invoices a
JOIN (SELECT id FROM invoices WHERE total > 300
      ORDER BY id LIMIT 20 OFFSET 200000) b
  ON a.id = b.id;
// 该片段可重复执行，结果保持不变
// 预期：控制台输出与上文描述一致
// 异常路径会在日志中打印具体原因
```

对比两次执行计划，改造后应当只走索引扫描而不是全表扫。

```sql
EXPLAIN ANALYZE
SELECT a.* FROM invoices a
JOIN (SELECT id FROM invoices ORDER BY id LIMIT 20 OFFSET 200000) b
  ON a.id = b.id;
```
